Model & evaluation

Model

This demo runs the CNN-BiLSTM baseline with 32 sampled RGB frames per clip. It predicts jump type from a single camera view.

Evaluation

On the FS-Jump3D held-out test split, this checkpoint scored 65.97% video-level accuracy and 0.652 macro F1 across 432 videos. Camera views of the same attempt were kept in one partition.

Scope

Use a trimmed, single-jump clip. Full-program detection, combination classification, rotation counting, and jump-quality scoring are outside this task.

Data context

Training and evaluation use controlled recordings from four skaters, with all four represented in each partition. Performance on unseen skaters or broadcast and phone footage has not been evaluated.
